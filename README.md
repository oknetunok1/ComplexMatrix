## 🚀 Функционал

### Матричные операции
* **Сложение матриц ($A + B$):** поэлементное сложение матриц одинаковой размерности.
* **Умножение матриц ($A \times B$):** вычисление произведения совместимых матриц ($Cols_A = Rows_B$).
* **Деление матриц ($A \times B^{-1}$):** правое умножение на обратную матрицу.
* **Транспонирование ($A^T$):** смена строк и столбцов местами.
* **Определитель ($\det A$):** вычисление детерминанта разложением по строке (миноры).
* **Обратная матрица ($A^{-1}$):** нахождение через транспонированную матрицу алгебраических дополнений.

---


## 🔢 Формат ввода данных

Комплексное число $z = a + bi$ вводится через пробел:  
`<действительная_часть> <мнимая_часть>`

| Математическая запись | Действительная часть (`Re`) | Мнимая часть (`Im`) | Консольный ввод |
| :--- | :---: | :---: | :---: |
| $3 + 4i$ | `3` | `4` | `3 4` |
| $5 - 2i$ | `5` | `-2` | `5 -2` |
| $7$ | `7` | `0` | `7 0` |
| $4i$ | `0` | `4` | `0 4` |
| $-i$ | `0` | `-1` | `0 -1` |
| $0$ | `0` | `0` | `0 0` |
| $-1.5 + 0.25i$ | `-1.5` | `0.25` | `-1.5 0.25` |

## 💻 Пример работы

```text
Выберите операцию:
1. Сложение матриц
2. Умножение матриц
3. Деление матриц (A * B^-1)
4. Транспонирование
5. Вычислить определитель
0. Выход
Ввод: 5

--- Ввод матрицы ---
Количество строк: 2
Количество столбцов: 2
Вводите элементы матрицы (действительная часть [пробел] мнимая часть):
Элемент [0][0]: 1 0
Элемент [0][1]: 2 0
Элемент [1][0]: 3 0
Элемент [1][1]: 4 0

Определитель: -2.0
```

## ⚠️ Обработка ошибок

* `IllegalArgumentException` — несовпадение размерностей матриц или попытка посчитать определитель неквадратной матрицы.
* `ArithmeticException` — деление на ноль или вырожденную матрицу ($\det = 0$).
